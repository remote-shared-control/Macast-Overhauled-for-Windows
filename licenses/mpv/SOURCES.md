- MPV exact source: https://github.com/mpv-player/mpv/tree/e471496c56
- FFmpeg exact source: https://github.com/FFmpeg/FFmpeg/tree/9a861e968
- Builder and native dependency recipes: https://github.com/shinchiro/mpv-winbuild-cmake/tree/20261021
- MPV license guide: https://github.com/mpv-player/mpv/blob/e471496c56/Copyright
- MPV installation/build distribution reference: https://mpv.io/installation/

The MPV executable is copied without modification. The source ZIP of this application covers Macast, the local NVA plugin, ModernZ Lua modifications and packaging, not the full dependency sources of the independently built native executable. Reproducible native rebuilds and public redistribution require the matching complete upstream build inputs and native dependency source archives.
